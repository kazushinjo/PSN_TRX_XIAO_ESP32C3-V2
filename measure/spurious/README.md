# 新スプリアス規格の測定手順（DSA815-TG・LAN 接続、JARD 提出用）

PSN TRX V2（50MHz 帯、J3E・A3E、定格 **1W**）の **帯域外領域のスプリアス発射** と **スプリアス領域の不要発射** を、RIGOL DSA815-TG で測って、JARD に出す資料（スペアナの画面と結果の表）を作る手順です。測定はスクリプト [`jard_spurious.py`](jard_spurious.py) でほぼ自動にできます。

> **このスクリプトは、測定器なしの模擬データ（`--dry-run`）でしか動かしていません。** DSA815 の実機で最初に使うときは、7 章の「初めて使うとき」の順に、画面と数値が合っているかを確かめてください。

測定の考え方は、JARD の資料「[アマチュア無線機の測定 〜スプリアス発射および不要発射〜](https://www.jard.or.jp/warranty/kihondata/spurious_measurement_method.pdf)」（2019-04-25）に合わせています。

## 1. 規格（50MHz 帯）

### 測る範囲と状態

| 領域 | 送信の状態 | 範囲 | スペアナの設定 |
|---|---|---|---|
| 帯域外領域 | **無変調** | fc ± 62.5kHz（50MHz 帯の J3E・A3E、JARD 資料の表 1）から、必要周波数帯幅（J3E 3kHz、A3E 6kHz）を除いた範囲 | RBW・VBW 10Hz〜1kHz（スクリプトは 100Hz）、検波 Positive Peak（表 2） |
| スプリアス領域 | **変調**（擬似音声、MAX HOLD） | 9kHz 〜 1GHz（送信周波数 100MHz 以下、表 4）から帯域外領域を除いた範囲 | RBW: 9k〜150kHz は 1kHz、150kHz〜30MHz は 10kHz、30MHz〜1GHz は 100kHz（表 6）、VBW は RBW と同じ |

変調の条件（JARD 資料の表 5）:

- **J3E**: 1.5kHz の正弦波で、空中線電力が飽和の **80%** になる入力レベルにしてから、同じレベルの擬似音声に切り替える
- **A3E**: 1kHz の正弦波で **変調度 60%**（スペアナで側波帯が搬送波の **−10.5dBc**）にしてから、同じレベルの擬似音声に切り替える

### 許容値（無線設備規則 別表第三号、JARD 資料の表 3・表 7）

| 定格出力 | 帯域外領域 | スプリアス領域 |
|---|---|---|
| **1W 以下（V2）** | **−10dBm（100μW）以下** | **−13dBm（50μW）以下** |
| 1W を超え 50W 以下 | 0dBm 以下 かつ −60dBc 以下 | −60dBc 以下 |
| 50W を超える | 0dBm 以下 かつ −60dBc 以下 | −13dBm 以下 または −70dBc 以下 |

V2（定格 1W、30dBm）は、帯域外 **−10dBm 以下**（1W で −40dBc）、スプリアス **−13dBm 以下**（1W で −43dBc）です。出力が尖頭 1W を超えると「1W を超え 50W 以下」の区分（−60dBc）になるので、`out` で尖頭 1W 以下にしてから測ってください（`manual/調整手順.md` 13）。V2.1（5W）の手順は V2.1 のリポジトリにあります。

## 2. 用意するもの

| もの | 内容 |
|---|---|
| スペクトラムアナライザ | RIGOL DSA815-TG（LAN で PC につなぐ） |
| 減衰器 | **30dB・5W 以上**（50Ω、1GHz まで）。1W（30dBm）を DSA815 の入力で 0dBm にする（JARD の目安は +10dBm 以下。20dB なら +10dBm） |
| ダミーロード | 50Ω・5W 以上（減衰器が 5W 以上の終端を兼ねるものなら不要） |
| 同軸ケーブル | 短いもの。BNC/N の変換も含めて、`pathloss` で損失を測る |
| PC | Python 3（`pip install matplotlib`。リグを自動で操作するなら `pyserial`、画面を PNG にするなら `pillow`） |
| 変調の音 | 擬似音声（JARD 資料が勧める CQ 出版の「測定用音源」（2017 年 6 月号）など）と 1kHz・1.5kHz の正弦波。PC の音声出力から **マイク端子** に入れる（レベルを下げる減衰器を入れる） |
| リグ | 本機。XIAO を USB で PC につなぐと、スクリプトが `freq`・`sb`・`tone` を送れる |

> DSA815 の入力の最大は +20dBm です。**送信機をスペアナに直接つながないでください。** 減衰器の入力側を送信機に、出力側をスペアナにつなぎます。

## 3. 接続

```
 本機 ANT ─── 減衰器 30dB（10W）─── 同軸 ─── DSA815-TG  RF INPUT
                                               DSA815-TG  LAN ─── PC（スクリプト）
 PC 音声出力 ─ 減衰 ─ マイク端子（擬似音声・正弦波）
 PC USB ─── XIAO（シリアル、--rig COM5 のとき）
```

## 4. DSA815 の準備

1. 電源を入れて **30 分** 以上あたためる。
2. **Utility → Interface → LAN** で IP アドレスを決める（DHCP か固定）。PC と同じネットワークにする。
3. PC で接続を確かめる（`192.168.0.50` は例。自分の IP に置き換える）:

   ```
   cd measure/spurious
   python jard_spurious.py --host 192.168.0.50 idn
   ```

   `RIGOL TECHNOLOGIES,DSA815,...` と出れば OK。つながらないときは、ポート（初期値 5555、`--port`）とファイアウォールを確かめる。

4. （勧める）減衰器とケーブルの損失を TG で測る。周波数ごとの損失で、2 倍波・3 倍波などの値を補正できます:

   ```
   python jard_spurious.py --host 192.168.0.50 pathloss --out-file pathloss.csv
   ```

   画面の指示どおり、1 回目はケーブルだけで TG OUTPUT → RF INPUT を直結し、2 回目は減衰器を入れます。50MHz・100MHz・150MHz などの損失が表示されます。TG の出力は小さい（−10dBm）ので減衰器は壊れません。

## 5. リグの準備（測る前に必ず）

1. ダミーロードと減衰器をつないで、`manual/送信IQ調整手順.md` の調整を済ませる。とくに次の 2 つは帯域外領域の値にそのまま出ます:
   - **キャリアの漏れ（VR5・VR6）**: J3E の無変調では、抑圧した搬送波の漏れが fc に出ます。**−10dBm（1W で −40dBc）より十分下** に合わせる（スクリプトはこの点も帯域外の判定に入れます）。
   - **AM の局発の漏れ**: AM では表示周波数の **4kHz 下**（fc − 4kHz）に局発の漏れが出ます。必要周波数帯幅（±3kHz）の外なので、**帯域外領域の判定に入ります**。VR5・VR6 を AM で確かめて −10dBm より下にする。
2. 出力: シリアルの `out` を、尖頭 1W を超えない値にする（`manual/調整手順.md` 13）。
3. 測る周波数を決める。JARD は「主に運用しているバンドやモード」での測定を求めています。例:
   - **J3E: 50.200 MHz**
   - **A3E: 51.500 MHz**（AM の区分は 51.000〜52.900MHz）
   - 余裕があれば上下の端（J3E 50.100・52.800MHz など）も測っておく

## 6. 変調の深さを合わせる（monitor）

スクリプトの `monitor` で、スペアナの値を見ながら合わせます（Ctrl+C で終わる）。

### J3E（1.5kHz で飽和の 80%）

```
python jard_spurious.py --host 192.168.0.50 monitor --freq 50.2 --mode J3E --att-db 30
```

1. PC から 1.5kHz の正弦波をマイク端子に入れ、PTT を押す。
2. 音量を少しずつ上げ、出力（W）が増えなくなったところ（飽和）を確かめる。表示の「最大」がその値。
3. 「最大の 80%」の W になるまで音量を下げる。**その音量のまま** 擬似音声に切り替える（PC の音量は動かさない）。

### A3E（1kHz で変調度 60%）

```
python jard_spurious.py --host 192.168.0.50 monitor --freq 51.5 --mode A3E --att-db 30 --tone 1000
```

1. リグを AM（`sb am` か設定モードの MODE）にし、PC から 1kHz の正弦波をマイク端子に入れて PTT を押す。
2. 表示の「変調度」が **60%（側波帯 −10.5dBc）** になるように、PC の音量（または `amd`）を合わせる。
3. その音量のまま擬似音声に切り替える。

## 7. 測る（measure）

### J3E

```
python jard_spurious.py --host 192.168.0.50 measure --freq 50.2 --mode J3E --rated-w 1 --att-db 30 --pathloss pathloss.csv --rig COM5
```

### A3E

```
python jard_spurious.py --host 192.168.0.50 measure --freq 51.5 --mode A3E --rated-w 1 --att-db 30 --pathloss pathloss.csv --rig COM5
```

スクリプトは次の順に進み、Enter を待つところで画面に指示を出します。

| 段階 | リグの状態 | スクリプトがすること |
|---|---|---|
| 1. 搬送波電力 | J3E は `tone 1500`（1.5kHz の単一トーン = 尖頭電力）、A3E は `tone 0`（搬送波だけ）。**PTT を押したまま** | スパン 50kHz で電力を測り、許容値（dBm）を決める |
| 2. 帯域外領域 | **無変調**: J3E は `tone 0`（音を入れない）、A3E は搬送波だけ | fc ± 75kHz、RBW 100Hz、3 回 MAX HOLD。fc ± 62.5kHz から必要周波数帯幅を除いた範囲の最大を判定 |
| 3. スプリアス領域 | **擬似音声**（6 章のレベル）。PTT を押したまま | 9k〜150kHz・150kHz〜30MHz・30MHz〜1GHz と、基本波の近く（fc ± 2MHz）を各 20 秒 MAX HOLD。2〜10 倍波と大きいものをスパンを絞って測り直す |

- `--rig COM5` を付けると、`freq`・`sb`・`tone` をスクリプトがリグに送ります（付けないときは画面の指示どおり手で入れる）。PTT だけは手で押します。
- 区間ごとの MAX HOLD の時間は `--hold`（秒）で変えられます。擬似音声の長さ以上にしてください。
- 同じ値で測り直すときは、そのままもう一度実行します（結果は日時のフォルダに分かれる）。

### 初めて使うとき

1. `python jard_spurious.py --dry-run measure --freq 50.2 --mode J3E --yes --hold 0` で、測定器なしで流れと出力のファイルを確かめる（模擬のスペクトルなので値には意味がない。わざと不適合が出るようにしてある）。
2. 実機では `--verbose` を付けて SCPI のやりとりを表示し、DSA815 の画面の設定（中心・スパン・RBW・オフセット）が指示どおりに変わるかを見る。
3. 搬送波電力が、通過形の電力計で測った値（減衰器の前）と ±1dB 程度で合うかを確かめる。合わないときは `--att-db`（または `pathloss`）を見直す。

## 8. 結果

`results/日時_周波数_型式/` に次のファイルができます。

| ファイル | 内容 |
|---|---|
| `summary.md` / `summary.csv` | 結果の表（JARD 資料の「測定結果サンプル」と同じ項目: 測定周波数・実測値 dBm・減衰値 dBc・規格限度値・適合）。CSV は Excel で開ける |
| `1_carrier*.png` | 搬送波電力 |
| `2_oob*.png` | **帯域外領域（基本波の近傍）** |
| `3_spur_1〜3*.png`・`3_spur_near*.png` | スプリアス領域（区間ごと） |
| `4_spur_worst*.png` | **スプリアス領域（その外側）で一番大きいもの** |
| `*_graph.png` | トレースのデータから描いたグラフ。赤い破線が許容値、灰色が判定から外した範囲 |
| `*.csv`・`result.json` | トレースのデータと全部の数値 |

- 測定器の画面そのもの（`*_graph` の付かない PNG）は、DSA815 が `:PRIVate:SNAP?` に答えたときだけできます（公開マニュアルにない命令なので、答えないことがある）。できないときは、`--usb-snap E:` を付けると DSA815 の USB メモリに画面を保存します（`:MMEMory:STORe:SCReen`、ドライブ名は DSA815 の Storage で確かめる）。手で **Print**（画面の保存）をしてもかまいません。
- 雑音のレベルが許容値の 6dB 以内のときは、スクリプトが注意を出します。そのときは `--spur-rbw-max 30000`（RBW を絞る）、`--int-att 20`（内部 ATT を下げる。入力が +10dBm 以下のときだけ）、または 50MHz を通さないハイパスフィルタを入れて `pathloss` で損失を測り直します。

## 9. JARD に出すもの

- JARD の手続きガイドでは、保証可能機器リストにない無線機について「主に運用しているバンドやモードでスプリアスを測定し、新スプリアス規格に適合していることが判別できる **スペアナ画面 2 種（基本波の近傍とその外側）**」を求めています。本スクリプトでは `2_oob`（近傍）と `4_spur_worst`・`3_spur_3`（外側）がそれにあたります。電波型式（J3E・A3E）ごとに用意します。
- 結果の表（`summary.csv` を JARD 資料の測定結果サンプルの形に転記）と、測定器（DSA815-TG、製造番号）・減衰器・測定日・測定者を添えます。
- **自作機の申請の種類**: JARD の「スプリアス確認保証」は *すでに免許を受けている無線機* が対象です。これから免許を受ける自作機は **基本保証（開設・変更）** になるはずです。どちらの書類にどの資料が要るか、測定器の較正（JARD のページに「較正等を受けて 1 年以内」とする記述がある）を求めるかは、出す前に JARD 保証事業センターに確かめてください（基本保証 03-3910-7263、スプリアス確認保証 03-3910-7286）。2026-11-26 の時点で JARD のインターネットでの申込は止まっていて、書面で申し込むよう案内されています。

### 判断が分かれるところ（JARD に確かめる）

- **J3E の「無変調」**: JARD の資料は帯域外領域を「無変調」で測るとしていますが、J3E は変調をかけないと電波（抑圧した搬送波の漏れ以外）が出ません。スクリプトは初期値で **音を入れない状態** で測り、搬送波電力（基準）は 1.5kHz の単一トーンで測ります。`--j3e-oob tone` にすると単一トーンのまま測ります。このときは **逆側の側波帯（fc − 1.5kHz）が帯域外領域に入り**、1W（許容値 −10dBm = −40dBc）では、PSN 方式の抑圧（40dB 前後）だと余裕がほとんどありません。
- **抑圧した搬送波の漏れ（fc）**: 必要周波数帯幅の下端にあたりますが、スクリプトは厳しめに帯域外の判定に入れています。
- **基本波の近く（fc ± 62.5kHz 〜 ±2MHz）**: RBW 100kHz では搬送波のすそが入るので、RBW 10kHz で測っています（CW 性のスプリアスの値は RBW によらず同じ）。

## 10. コマンドの一覧

| コマンド | 内容 |
|---|---|
| `idn` | 接続の確認 |
| `pathloss [--tg-level -10] [--out-file pathloss.csv]` | TG で減衰器・ケーブルの損失を測る（100kHz〜1GHz） |
| `monitor --freq F --mode J3E\|A3E [--tone 1000]` | 変調の深さを合わせるための連続表示 |
| `measure --freq F --mode J3E\|A3E [オプション]` | 搬送波・帯域外領域・スプリアス領域をまとめて測る |

`measure` の主なオプション: `--rated-w`（定格 W、初期値 1）、`--att-db`（外部の減衰 dB、初期値 30）、`--pathloss`、`--int-att`（内部 ATT、初期値 30）、`--oob-rbw`（初期値 100Hz）、`--hold`（区間ごとの秒、初期値 20）、`--j3e-oob none|tone`、`--rig COM5`、`--usb-snap E:`、`--spur-rbw-max`、`--outdir`。共通: `--host`、`--port`（初期値 5555）、`--dry-run`、`--verbose`。
