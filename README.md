# PSN_TRX_XIAO_ESP32C3-V2

Seeed Studio XIAO ESP32C3 + Si5351 を使用した PSN 方式 SSB トランシーバー（KiCad 10.0）。

> **V2 Ver 1.2（作業中）**: [PSN_TRX_XIAO_ESP32C3](https://github.com/kazushinjo/PSN_TRX_XIAO_ESP32C3) を元に、受信部をダイレクトコンバージョンから SSB のシングルスーパー（IF 12MHz・ラダーフィルタ・積検波）に変更した。回路図・基板（134.1 × 129.7mm、配線済み・DRC エラー 0）・ファームウェア（ビルドのみ）・部品表・シミュレーションは V2 に更新済み。**実機は未確認**。製造データ（ガーバー・JLCPCB 用ファイル、`kicad/production/`）は 2026-11-06 に V2 Ver 1.2 の基板から `kicad/make_production.py` で出力済み（基板シルク「V2 Ver 1.2」）。部品実装図（`docs/PSN_TRX_部品実装図.pdf`、ブロック別 13 ページ＋調整箇所）・部品配置図（`kicad/PSN_TRX_部品配置図.pdf`）・調整手順（[`manual/調整手順.md`](manual/調整手順.md)）・操作説明書（[`manual/README.md`](manual/README.md)）・送信 I/Q の調整手順、組み立て説明書・評価試験報告書・回路図論理検証レポート・VFO 改造仕様書（docx）は V2 Ver 1.2 に更新済み。

## 概要

50MHz 帯 PSN（位相シフト網）方式 SSB トランシーバー。VXO（水晶発振器）を
Si5351A クロックジェネレーターによる VFO に置き換え、Seeed Studio XIAO ESP32C3 でデジタル制御する。

Si5351 の CLK0（0°）/ CLK1（90°）二相出力を直接バランスドモジュレーターへ供給することで、
従来の RF PSN（RC 位相シフト回路）も不要となる。

## 主な仕様

| クロックジェネレーター | Si5351A（AE-Si5351A モジュール、I2C 制御） |
| 周波数範囲 | 50.000 〜 51.000 MHz（6m バンド） |

| CLK2 出力（V2） | 受信中だけ BFO（約 12MHz、PLLB）→ R19・R20 → U2。USB はフィルタの通過域の下端の外、LSB は上端の外（シリアルの `bfo usb <Hz>` / `bfo lsb <Hz>` で合わせて保存） |
| チューニングステップ | 10Hz / 100Hz / 1kHz / 10kHz / 100kHz |
| 表示 | Nextion NX4832T035（3.5 インチ シリアル LCD、標準）または OLED SSD1306 128×64（コンパイル時に選択） |
| 周波数記憶 | NVS（電源 OFF 後も保持） |
| S メーター・AGC | V2: IF 増幅（Q6・Q7）の出力を Q8 で増幅して AD8307（対数検波、25mV/dB）で測り、ADS1015（秋月 AE-ADS1015、I2C 0x48）で XIAO が読む。AGC は Q21 で RF 増幅 Q3・IF 増幅 Q7 のゲートを下げる（FAST / SLOW / OFF）。調整値はスケッチの RSSI_S9_MV・AGC_TARGET_MV |

| 操作 | エンコーダを押すと設定モード（ダイヤルで RIT / STEP / AGC を選び、押して値の変更、もう一度押して確定） |

## ハードウェア構成

```
Seeed Studio XIAO ESP32C3 ─ メインコントローラ
├── Si5351A モジュール (AE-Si5351A) ─ I2C クロックジェネレーター
│   ├── CLK0  送信中 0° → バランスドモジュレーター 1（D4/D5）／受信中 第 1 局発 → Q4 → L3 → U1
│   ├── CLK1  送信中だけ 90° → バランスドモジュレーター 2（D6/D7）
│   └── CLK2  受信中だけ BFO → R19・R20 → U2（積検波）
├── ADS1015 モジュール（I2C 0x48）─ A0 = AD8307 の出力（S メーター・AGC）
├── Nextion NX4832T035 LCD（D6/D7 UART）または OLED（D4/D5 I2C）
├── ロータリーエンコーダ（A=D3, B=D1, SW=D9）
├── A2: 送信中のマイク音声（U5A → C65・R52、R73/R74 で 1.65V バイアス）→ 複素 FIR で I/Q を作る
│        （V2 では受信音は来ない）
├── D10: 受信中は AGC の PWM（→ R75・C104 → R76 → Q21 で Q3・Q7 のゲートを下げる）
│        送信中は PDM の I（→ R53・C66・R54・C67 → C70 → Q15）
├── D8: PDM の Q（→ R55・C68・R56・C69 → C72 → Q16、送信中だけ出力）
└── 送信検出 D0（TX12V → R77/R78 → Q22、送信中 LOW）

  受信と送信はリレー K1 で電源（RX12V／TX12V）が切り替わるので、A2・D10 を送受で使い分けられる。
  D0 は起動設定ピン（GPIO2）なので、PTT を押したまま電源を入れない

1W PA: RD06HVF1 (N-ch RF MOSFET) @ 12V, Class AB
```

## 1W パワーアンプ（Q19）

前段（2SC1815 等）の出力（約 20〜30mW）を増幅する終段アンプ。

| 項目 | 内容 |
|---|---|
| トランジスタ | **RD06HVF1**（三菱電機 N-ch RF MOSFET, 175MHz, 6W, TO-220F） |
| 電源電圧 | 12V |
| 動作クラス | Class AB |
| 静止電流 Idq | 200〜400mA（VR7 で調整） |
| 出力 | 約 1W @50MHz |
| 出力 LPF | 7 素子チェビシェフ＋2 倍波トラップ: C94（0.001µF、直流カット）→ C98 39pF → L16（T-50-10 9T）→ C99 82pF＋TC3 30p → L17（10T）→ C101 100pF ∥ トラップ（L18 T-30-6 8T ＋ C100 5pF ∥ TC4 10p、101MHz）→ L19（8T）→ C102 68pF → K1。C98 には Q19 の出力容量 Coss 約 18pF が並列に入る。TC4 を合わせると 2 倍波 −70〜−76dB、3 倍波 −75〜−80dB、挿入損失 0.41〜0.53dB（計算値） |
| 電源 | 送信 12V（リレー K1 の NO 側）、RFC1 10µH 経由。バルク C96 100µF |

### バイアス回路

```
送信12V → R70(330Ω) → VR7(500Ω) の 1 番 ─ VR7 の 3 番 → GND
                         VR7 ワイパー(2 番) → R69(10Ω) → Q19 ゲート
```

- ゲート電圧の可変範囲は 0〜約 7.2V（13.8V 電源では約 8.3V）。**最初の送信前に VR7 を GND 側（ゲート 0V）いっぱいに回しておく**（上側いっぱいだと電流が流れすぎて Q19 を壊すおそれがある）
- 無変調で送信し、VR7 を少しずつ回してドレイン電流 (Idq) を 200〜400mA に合わせる。RD06HVF1 のしきい値電圧 Vth は 1.9〜4.9V（データシート）で、データシートの代表特性では Vgs 約 4V から電流が流れ始め、約 5V で 0.3A。合わせたときのゲート電圧は個体によって 4〜6V 程度になる。電流は Vgs に対して急に増えるので、5V を超えたらゆっくり回す
- Q19 のソースは GND 直結

詳細は `docs/PSN_TRX_VFO改造仕様書.docx` を参照。

### ヒートシンク

RD06HVF1（Q19）には秋月電子 **17PB046**（GEC ヒートシンク、46.2×17×25mm、黒アルマイト、熱抵抗 11.9℃/W）を使用（基板 Ver 1.5 から。それまでは 20PB020、15.8℃/W）。
Q19 のタブを基板図の上側（HS1 側）に向け、タブの M3 穴でヒートシンクの取付面にネジ止めする。ヒートシンクの脚ピン（φ1.4、ピッチ 30mm、取付面から 3mm）用に、基板へ φ1.6 の穴（NPTH）を 2 個設けている（HS1）。M3 ねじ穴は基板面から 19mm の高さ。
高さは 20PB020 と同じ 25mm なのでケースはそのまま使える。ヒートシンクの右端がふた上の LCD 基板の下に入らないよう、Q19 とヒートシンクは Ver 1.4 より 2.5mm 左にある（LCD 基板の端から約 1.5mm 離れる）。

回路図のネットリストから定数を直接読み込み、KiCad 同梱の ngspice（libngspice）で計算した結果です（V2 Ver 1.1、2026-11-05）。スクリプトと全結果は [`kicad/sim/`](kicad/sim/) にあり、`./run.sh` で再計算できます（結果は `kicad/sim/results.txt`）。トランジスタはデータシートの代表値から作った簡易モデルなので、実機では測定で確認してください。

### PA 出力 LPF（5 素子 → 7 素子＋2 倍波トラップ）

LPF だけの周波数特性（50Ω 終端、10〜500MHz）。左が Ver 1.7 までの 5 素子、右が Ver 1.8 の 7 素子＋101MHz トラップ（TC4 を合わせた状態）。

![PA 出力 LPF の周波数特性](docs/images/lpf_response_10_500MHz.png)

PA 出力のスペクトル。PA（RD06HVF1、シングル AB 級）自身の高調波を 2 倍波 約 −20dBc・3 倍波 約 −27dBc とし、上の LPF を通した値です。出力に対する比（dBc）で読む図です（図のタイトルの「10W」は計算時の基準値で、本機の出力は約 1W）。破線は 1W を超える場合の許容値 −60dBc。

![PA 出力のスペクトル](docs/images/pa_output_spectrum.png)

| | 5 素子（Ver 1.7 まで） | 7 素子＋トラップ（Ver 1.8、TC4 調整後） |
|---|---|---|
| LPF の減衰（2 倍波 101MHz） | −27〜−31dB | −70〜−76dB |
| LPF の減衰（3 倍波 151.5MHz） | −47〜−51dB | −75〜−80dB |
| 挿入損失（50.5MHz） | 約 0.17dB | 0.41〜0.53dB |
| 出力の 2 倍波（図の例） | −50.5dBc | −94.5dBc |
| 新スプリアス規定（1W 以下 −43dBc／1W 超 −60dBc） | 1W 超では満たさない | 満たす見込み |

減衰の範囲は、L19/L16/L17 ±7%・Q19 の出力容量 18〜25pF・トラップのコイル ±7% のすべての組み合わせでの値です。**TC4 を合わせないと 2 倍波が −30dB 程度に戻ることがある**ので、組み立て後に 2 倍波（約 101MHz）が最小になるよう TC4 を調整してください（manual/調整手順.md の手順 9、組み立て説明書 7 章）。規定への適合は実測（スペクトラムアナライザ）で確認が必要です。

### 受信の前段の利得

前段の利得は R5（2.2kΩ）と L2 のタップ（RX12V 側から 3 回目）で約 23dB に抑えています（10kΩ なら +28dB・雑音指数 1.0dB だが、混合器に入る信号が 8dB 大きくなる）。その分は Q9 の利得（R29 ÷ R28 ≒ 12）で戻しています。

### 送信 I/Q の位相差（Ver 2.0）

AF の周波数を 100〜3200Hz でスキャンし、I と Q の位相差の 90° からのずれ（上）、振幅差（中）、そこから決まる逆側帯波の抑圧（下）を計算したもの。U7 の FIR はファームウェアと同じ係数（int16 に丸めた後）、その後ろの RC〜変調器入力は ngspice で計算しています（`kicad/sim/iq_scan.py`）。FIR は I 側が左右対称・Q 側が逆対称の係数なので位相差はちょうど 90° になり、抑圧は振幅のわずかなリップルで決まります。RC がずれたときのずれは周波数に比例する（遅延の差になる）ので、`iqd`（遅延差）・`iqa`（利得差）でほぼ打ち消せます。3.3kHz より上は FIR の阻止域（出力がほぼ 0）なので表示していません。

![送信 I/Q の位相差](docs/images/iq_phase_scan.png)

### 不要側波帯の抑圧比（Ver 2.0）

上は音声周波数ごとの抑圧比、下は試験トーン 1kHz（`tone 1000`、USB）を送信したときにスペクトラムアナライザで見える形です（`kicad/sim/sideband.py`）。部品が定数どおりなら約 70dB、RC が I/Q で ±3% ずれても `iqd`・`iqa` の補正で約 50〜60dB。ただし RF 側（Si5351 の 2 出力・変調器）に 1°・0.1dB のずれがあるだけで約 39dB になり、実機の抑圧比はほぼ RF 側で決まります（RF 側は計算に含めていないので、参考の線として重ねています）。

![不要側波帯の抑圧比](docs/images/sideband_suppression.png)

実機での `iqd`・`iqa` の合わせ方（試験トーンと SDR・受信機を使う手順、記録表つき）は [`manual/送信IQ調整手順.md`](manual/送信IQ調整手順.md) にまとめています。
