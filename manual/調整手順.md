# PSN_TRX-V2 調整手順（基板 V2 Ver 1.0）

組み立てが終わった基板を、受信 → 送信の順に調整する手順です。番号は [`docs/PSN_TRX_部品実装図.pdf`](../docs/PSN_TRX_部品実装図.pdf) の最終ページ「調整箇所」の丸数字と同じです。送信 I/Q（手順 12）の詳しい測り方は [`送信IQ調整手順.md`](送信IQ調整手順.md) にあります。

> 送信の調整は、必ず 50Ω のダミーロードをつないで行ってください。アンテナにつないで調整すると、不要な電波が出ます。

## 0. 全体の流れ

| 1 | 電源と各部の電圧 | IC1・U2・U6 | +5V・3.3V・5V_RX、各段の直流電圧が表の範囲 | テスター |
| 2 | IF 増幅の電流（J310 のときだけ） | R5 | R5 の両端 1.2〜1.8V | テスター |
| 3 | 第 1 局発 | L9（コア） | U4 のキャリア入力が最大（約 100mVrms） | オシロスコープ（なければ受信音） |
| 4 | 受信 RF 前段 | TC3・TC4 | 50.5MHz で rssi 最大 | 信号発生器（なければ弱い信号） |

## 1. 準備

### 1.1 必要なもの

- 直流安定化電源 12V（電流制限つき。最初は 300mA に制限）
- テスター
- 50Ω ダミーロード（2W 以上）
- USB-C ケーブルとパソコン（Arduino IDE のシリアルモニタ、**115200bps・改行（LF）あり**）
- あれば: 50MHz の信号発生器（−73dBm〜−110dBm を出せるもの、またはアッテネータ）、オシロスコープ（100MHz 以上）、スペクトラムアナライザ、SDR（RTL-SDR など）

### 1.2 シリアルモニタで使うコマンド

| 入力 | はたらき |
|---|---|
| （何も入れない） | 受信中は 0.1 秒ごとに `rssi 1234 mV  agc 0  S 0.0 dB` が出る（AD8307 の出力・AGC の量・S メーターの値） |
| `bfo` | BFO の今の値を表示 |
| `bfo usb 11999900` / `bfo lsb 12003100` | BFO を変えて保存（11,990,000〜12,010,000Hz） |
| `dsp` | 送信音声の設定を表示 |
| `tone 1500` / `tone 0` | 送信中に試験トーンを出す / 止める |
| `out 10` / `alc -20` / `iqa` / `iqd` / `sb` | 送信レベル・ALC・I/Q の補正（[送信IQ調整手順.md](送信IQ調整手順.md)） |
| `w` | 送信音声の設定を保存 |

AGC の切り替え（FAST・SLOW・OFF）は、TUNE つまみを押して設定モードに入って行います。

### 1.3 書き込み

XIAO に最新のスケッチ（`PSN_TRX_XIAO_ESP32C3/`）を書き込みます。D0（送信検出）と D9（エンコーダの SW）は起動設定ピンなので、**PTT やつまみを押したまま電源を入れないでください**。

## 2. 受信の調整

### 手順 1　電源と各部の電圧

1. XIAO・Si5351・ADS1015 のモジュールを差さずに、電流制限 300mA で 12V を入れ、異常な電流が流れないことを確かめます。
2. 電源を切ってモジュールを差し、もう一度電源を入れて、受信状態で次の電圧を測ります（GND 基準）。

| 測る所 | 目安 | 外れたとき |
|---|---|---|
| IC1（R-78E）の出力（+5V） | 4.9〜5.1V | IC1 の向き・L12・C52 |
| U2（LP2950）の出力（Si5351 の電源） | 3.2〜3.4V | U2 の向き |
| U6（78L05）の出力（5V_RX） | 4.8〜5.2V（受信中だけ。送信中は 0V） | U6 の向き・K1 |
| R66 の両端（Q20・Q25 の電流） | 0.8〜2.2V（標準 1.5V） | Q20・Q25 のピン配置（1 D・2 S・3 G） |
| Q21 のエミッタ | 0.8〜1.2V | R71・R72 |
| Q22 のエミッタ | 0.8〜1.2V | R82・R83 |
| Q23 のコレクタ | 2.7〜4.9V | R96〜R98 |
| J4 の 2 番（Q2 の G2、AGC OFF・RF つまみ最大） | 3.6〜4.6V | J4 の配線・Q17 |

### 手順 2　IF 増幅の電流（Q4・Q5 に J310 を使ったときだけ）

受信状態で R5（120Ω）の両端の電圧を測ります。**1.2〜1.8V（10〜15mA）**なら調整は不要です。

- 2.4V（20mA）を超えるとき: R5 を 180〜330Ω に替える
- 0.84V（7mA）未満のとき: R5 を 82〜100Ω に替える

Q2 に 3SK59 を使ったときは調整不要です。

### 手順 3　第 1 局発（L9）

局発は Si5351 の CLK0（受信周波数 − 12MHz、38〜39MHz）を Q11 で増幅し、L9（C29 27p と同調）から R68・R69 で U4 のキャリア入力へ送ります。

1. 周波数を 50.500MHz にします（局発は 38.500MHz）。
2. オシロスコープ（10:1 プローブ）を U4 の 7 番ピン側（C88 と R69 の間）に当て、L9 のコアを振幅が最大になるように回します。
3. 振幅は **約 0.28Vpp（100mVrms）** が目安です。0.45Vpp を超えるときは R68 を大きく（680Ω〜1kΩ）、0.15Vpp に届かないときは R68 を小さく（330Ω）します。
4. 50.0MHz と 51.0MHz でも振幅が大きく下がらない（半分以上ある）ことを確かめます。

オシロスコープがないときは、手順 4 の信号を受けながら、rssi（または受信音）が最大になるように L9 を合わせます。

BFO（CLK2）も同じように U5 の 7 番ピン側（C102 と R78 の間）で約 0.28Vpp であることを確かめます（調整箇所はありません。違うときは R77 で合わせる）。

### 手順 4　受信 RF 前段（TC3・TC4）

1. AGC を OFF、上面の RF つまみを右いっぱい（最大感度）にします。
2. アンテナ端子に 50.500MHz・−100dBm 前後の無変調の信号を入れます（信号発生器がないときは、弱いビーコンや遠くの局の信号を使う）。
3. シリアルモニタの `rssi` を見ながら、TC3（入力同調）→ TC4（出力同調）の順に最大になるように合わせ、もう一度 TC3・TC4 を繰り返します。
4. 計算では TC3 が約 9pF、TC4 が約 18pF（30pF のトリマで、それぞれ回転のおよそ 1/3・2/3）で合います。トリマの端で最大になるときは、C80（10p）・C82（5p）を確かめてください。
5. 50.000MHz と 51.000MHz で同じ強さの信号を入れ、rssi の差が 25mV（1dB）程度以内であることを確かめます（計算では −0.3dB・−0.6dB）。

### 手順 5　IF の同調（確認。必要なときだけ）

L22（4.7µH）と C11（IF 増幅の出力）、L23（4.7µH）と C108（S メーター増幅の出力）は固定の同調回路です。計算では同調点が C11 側 12.88MHz、C108 側 10.26MHz と 12MHz から少しずれていますが、12MHz でも必要な利得（積検波へ +12.5dB、AD8307 へ +21.5dB）が出るので、ふつうは調整不要です。

次のときだけ、コンデンサを差し替えて比べます（実装の浮遊容量で変わるので、実際に比べて大きい方を選ぶ）。

| 症状 | 差し替える部品 | 試す値（計算で 12MHz に合う見込み） |
|---|---|---|
| S9（−73dBm）を入れても rssi が 1.5V に届かない | C108（33p） | 22p・27p |
| 受信音が小さく、ノイズばかり大きい | C11（33p） | 39p・47p |

### 手順 6　BFO

ラダーフィルタの通過域は水晶の運動定数で変わる（計算では 12MHz の +220〜+2810Hz）ので、BFO で音声の帯域を合わせます。

1. `bfo` で今の値を表示します（初期値 USB 11,999,900Hz、LSB 12,003,100Hz）。
2. 表示周波数を 50.500MHz（USB）にし、信号発生器の周波数を 50.500300MHz（300Hz の音）から 50.503000MHz（3000Hz）まで動かして、受信音（または rssi）が下がり始める低い側・高い側の周波数を調べます。
3. 低い側が **約 300Hz**、高い側が **約 2700〜2900Hz** になるよう、`bfo usb <Hz>` で BFO を 50Hz ずつ動かします。
   - 低い音が出すぎる（ハム・こもった音）: BFO を下げる（例 11999900 → 11999850）
   - 低い音が足りない（シャリシャリした音）: BFO を上げる
4. LSB に切り替え、同じように `bfo lsb <Hz>` で合わせます（LSB では向きが逆で、低い音が出すぎるときは BFO を上げる）。
5. BFO を変えても表示周波数はずれません（局発をスケッチが合わせる）。

### 手順 7　S メーター・AGC

S メーターは AD8307（U7）の出力を ADS1015（J11）で読み、`rssi` の値から計算します。スケッチ冒頭の「Sメーター・AGC の調整値」を実機の値に直して、書き込み直します。

1. AGC を OFF、RF つまみを右いっぱいにします。
2. 50.500MHz に **−73dBm（50µV、S9）** の無変調の信号を入れ、`rssi` の値（mV）を読みます（計算の見込みは約 1900mV）。
3. スケッチの `RSSI_S9_MV` にその値を、`AGC_TARGET_MV` にその値 − 150（S9 の 6dB 下）を入れます。
4. 信号を −93dBm（S9 −20dB）にして rssi が約 500mV 下がる（25mV/dB）ことを確かめます。大きく違うときは `RSSI_MV_PER_DB` を実測値（mV ÷ 20）に直します。
5. AGC を FAST にし、信号を S9+40dB（−33dBm）まで上げたとき、J4 の 2 番（Q2 の G2）が 0.1〜0.2V まで下がり、受信音が大きく変わらないことを確かめます。計算では PWM 値 700 前後で効き始め、1000 前後で効き切るので、`AGC_DUTY_FULL` は 1000 前後が目安です（初期値 1400 のままだと強い信号で S メーターの換算が頭打ちになる）。
6. 書き込み直した後、もう一度 S9 で S9 を指すことを確かめます。

## 3. 送信の調整

送信の調整の前に、**ANT に 50Ω のダミーロードをつなぎます**。

### 手順 8　終段 Idq（VR2）

1. VR2 をゲート電圧が最小（0V 側）になる向きに回し切ります。
2. 電流制限を 500mA にし、マイクをつながず（`tone 0`）PTT を押して送信状態にします。
3. 電源電流の増え方（Q3 のドレイン電流）を見ながら VR2 を少しずつ回し、**Idq 200mA** に合わせます。RD06HVF1 はゲート電圧が約 4V を超えたあたりから急に電流が増えるので、そこからはゆっくり回します（合わせたときのゲート電圧は個体により約 4〜6V）。
4. 数分送信して放熱器 HS1 の温度と電流が安定していることを確かめます。

### 手順 9　2 倍波トラップ・出力 LPF（TC2 → TC1）

1. `out 10`・`tone 1500` にして送信し、ダミーロードの手前（アッテネータ経由）でスペクトラムアナライザを見ます。
2. **TC2** を第 2 高調波（約 101MHz）が最小になるように合わせます（計算では 5〜6.5pF の付近。トリマの最小側で最小になるときは C72 5p を 3p に替える）。
3. 次に **TC1** を基本波の出力が最大（SWR 最小）になるように合わせます。
4. 2 倍波が基本波より **60dB 以上低い**（−60dBc 以下）ことを確かめます。

スペクトラムアナライザがないときは、L17・C72・TC2 を付けた後、送信回路の電源を入れる前にディップメーターで L17＋C72∥TC2 を 101MHz に合わせます。TC2 を合わせないと 2 倍波が −30dBc 程度にしか下がらないことがあります。

### 手順 10　送信の同調（L8・L7・L6）

1. `tone 1500` で送信し、ダミーロードの両端の電圧をオシロスコープ（または RF 電圧計）で見ます。
2. L8（変調器の出力）→ L7（Q10）→ L6（Q8）の順に、コアを出力が最大になるように合わせ、もう一度繰り返します。
3. 最後に TC1 をもう一度出力最大に合わせ直します。

### 手順 11　キャリアバランス（VR3・VR4）

1. `tone 0`（無変調）で送信します。
2. SDR か受信機で送信周波数のキャリア（漏れ）を見ながら、VR3（CLK0 側）・VR4（CLK1 側）を交互に、キャリアが最小になるように合わせます。
3. 目安は **−30dBm 以下**（1W に対して 60dB 以上低い）です（計算では VR3・VR4 とも中点付近で最小）。

### 手順 12　送信 I/Q（VR6・VR7、`iqa`・`iqd`）

[送信IQ調整手順.md](送信IQ調整手順.md) の 3〜7 章のとおりに行います。流れは次のとおりです。

1. `out 5`・`alc -20` にし、`tone 1000` で希望波が送信周波数 ＋1kHz（USB）に出ることを確かめる（逆なら `sb lsb`）。
2. `tone 1500` で、送信周波数 −1.5kHz の逆側帯波が最小になるよう `iqa`（0.1dB → 0.02dB 刻み）と `iqd`（0.5µs → 0.1µs 刻み）を交互に合わせる。
3. `tone 500` と `tone 2500` で抑圧がそろわないときは `iqd` で合わせる。どの音でも同じだけ残るときは RF 側の位相のずれなので、VR6・VR7 で合わせる（計算では VR6 0.9・VR7 0.6 付近で 90°）。
4. 目安は抑圧 **40dB 以上で合格、50dB 以上で良好**です。

### 手順 13　送信レベル・最終確認

1. `tone 0`・`out 10`・`alc -20` に戻し、`w` で保存します（`out 5` のまま保存しない）。
2. マイクで話して、出力（尖頭で約 1W）と ALC メーターの振れを確かめます。送信開始の 0.45 秒は無音になるのが正常です。
3. スペクトラムアナライザで、2 倍波・3 倍波が −60dBc 以下、帯域外に広がりがないことを確かめます。
4. 送信後に Idq（手順 8）が変わっていないことを確かめます。
5. ダミーロードを外してアンテナをつなぎ、実際の信号で受信できること、相手局からのレポートで送信の音質を確かめます。
