# 送信 平衡変調器・ドライバ（Q17・Q18）の動作確認

送信 I/Q（Q15・Q16 のコレクタ）が正しく出ることを確かめた後（[送信IQ波形確認記録.md](送信IQ波形確認記録.md)）、その先の **平衡変調器（D4〜D7・L12）とドライバ（Q17・Q18）** が正しく働くかを、終段 Q19 を付ける前にオシロスコープとテスターで確かめる手順です。

- Q19（RD06HVF1）は付けないので、電波はほとんど出ません。それでも念のため ANT に 50Ω のダミーロードをつないでおきます。
- 目安の値は V2 の回路図からのシミュレーション（`kicad/sim/full.py` の送信の回路、2026-11-25）です。計算は Q19 を付けた状態なので、Q19 がないと L14 の二次側が軽くなり、実際は少し大きめに出ることがあります。

## 1. 信号の経路

```
CLK0(0°) ─ C74 ─ L8・C76・C77 ─ VR3 ─ C80 ─ VR5 ワイパ ─ D4・D5 ─┐
  Q15（I の音声）─ C71 ─ L10（1mH）─────┘                        │
                                                                    ├─ L12 一次（C84 15p、CT は GND）
CLK1(90°) ─ C75 ─ L9・C78・C79 ─ VR4 ─ C81 ─ VR6 ワイパ ─ D6・D7 ─┘
  Q16（Q の音声）─ C73 ─ L11（1mH）─────┘

L12 二次 → Q17（2SK439）→ L13 → C88 → Q18（2SC1815）→ L14 → C92・C93・L15 →（Q19）
```

- 送信中は Si5351 の CLK0（0°）と CLK1（90°）が表示周波数（例 50.5MHz）を出します。受信中の CLK0 は局発（38〜41MHz）なので、測るのは必ず送信中（PTT を押した状態）です。
- VR5・VR6（1k）はキャリアバランス、VR3・VR4（500）はキャリアのレベルです。

## 2. 用意する部品と道具

ここで付ける部品（どれももともと付ける部品）:

| ブロック | 部品 |
|---|---|
| キャリアの経路 | C74〜C81・L8・L9・VR3・VR4・R63・R64（受信の局発でも使うので、もう付いていることが多い） |
| 平衡変調器 | D4〜D7（1N60）・VR5・VR6・L10・L11・C82・C83・C84・L12 |
| ドライバ | Q17・R65・C85・L13・C86・C87・C88・Q18・R66〜R68・C89・L14・C90・C91 |
| （あれば） | C92・C93・L15（L14 の二次側の負荷。Q19 は付けない） |

- オシロスコープ（50MHz が見えるもの。DS1202Z-E でよい）、10:1 プローブ、**短い GND スプリング**（50MHz では長い GND ワニ口だと波形が乱れる）
- テスター（電圧・ダイオード）
- USB-C でパソコンにつなぎ、シリアルモニタ（115200bps・LF）で `tone`・`out` を使う
- 12V の安定化電源（電流制限 300mA）、50Ω ダミーロード

## 3. 手順

### 手順 1　付ける前：D4〜D7（1N60）を選ぶ

1. テスターのダイオードレンジで、順方向 **0.2〜0.35V**、逆方向は導通しないことを確かめます。
2. 4 本の値がなるべくそろったものを使います（そろっているほどキャリアの漏れが小さく、VR5・VR6 が中点近くで合う）。
3. 向きに注意します。**D4・D6 のアノードが L12 の SA（1 番）側、D5・D7 のカソードが L12 の SB（3 番）側**です。

### 手順 2　直流：PTT を押して送信状態、`tone 0`

| 測る所 | 目安 | 外れたとき |
|---|---|---|
| TX12V（C87・C91） | 11〜13.8V（送信中だけ） | K1・PTT の配線 |
| R65 の両端（Q17 のソース） | 0.3〜0.4V（約 6.7mA） | Q17 の向き（1 G・2 S・3 D） |
| Q17 のドレイン、Q18 のコレクタ | ほぼ TX12V | L13・L14 の巻線の導通 |
| Q18 のベース | 約 2.1V | R66・R67 |
| Q18 のエミッタ（R68 100Ω） | 1.2〜1.8V（12〜18mA） | Q18 の向き（1 E・2 C・3 B） |
| VR5・VR6 のワイパ | ほぼ 0V | L10・L11、C71・C73 の漏れ |

### 手順 3　キャリア：`tone 0`、10:1 プローブで 50MHz

| 測る所 | 目安 |
|---|---|
| C77・C79（VR3・VR4 の入力側） | 約 4Vpp |
| VR5・VR6 のワイパ | それぞれ約 0.65Vpp、2 つがほぼ同じ大きさ。CLK1 側が約 5ns（90°、50.5MHz）遅れる |
| Q18 のコレクタ（合わせる前） | 約 50mVpp のキャリアの漏れ |

Q18 のコレクタを見ながら、VR5・VR6 を交互に回してキャリアが一番小さくなる所に合わせます（数 mVpp 以下）。これがキャリアバランス（[調整手順](調整手順.md) 手順 11）の大まかな合わせになります。計算では VR5・VR6 とも中点付近で最小です。

### 手順 4　変調：`out 10`・`tone 1000`

1. **音声が来ているか**: C82（L10 の音声側）と C83（L11 の音声側）で、1kHz の正弦波が **0.1〜0.4Vpp** あり、2 つがほぼ同じ大きさであることを確かめます。
2. **同調**: Q18 のコレクタを見ながら L12 → L13 のコアを最大に合わせます（目安 **0.7〜1.3Vpp**）。次に L14 の二次側（C92 側）を見ながら L14 を最大に合わせます（目安 **0.3〜0.6Vpp**）。もう一度 L12 → L13 → L14 を繰り返します。
3. **包絡線を見る（一番大事）**: Q18 のコレクタを見たまま時間軸を **0.2ms/div** にします。I と Q が両方正しく働いていれば、1 本の SSB 信号なので **包絡線は平ら**になります。

| 包絡線の様子 | 原因 |
|---|---|
| 平ら | 正常 |
| 0.5ms ごとに 0 近くまでくびれる（DSB の形） | 片方の変調器が働いていない。VR5・VR6 のワイパに音声が来ているか、D4〜D7 の向き・はんだを確かめる |
| 2kHz（周期 0.5ms）のうねり | I と Q の振幅・位相のずれ（逆側帯波が残っている） |
| 1kHz（周期 1ms）のうねり | キャリアの漏れ（手順 3 をやり直す） |
| 振幅がほとんど出ない | L12・L13 の同調、Q17・Q18 の直流（手順 2） |

**うねりから抑圧の目安を出す**: 包絡線の最大を Vmax、最小を Vmin とすると、逆側帯波の抑圧はおよそ

  20·log((Vmax − Vmin) / (Vmax + Vmin)) [dB]

です（例 Vmax 1.1V・Vmin 0.9V → −20dB）。オシロスコープで読めるのは −30dB 程度までなので、40dB 以上に詰めるのは Q19 を付けた後に SDR で行います（[送信 I/Q の調整手順](送信IQ調整手順.md)）。

4. **直線性**: `out 5` → `out 10` → `out 20` と上げ、Q18 のコレクタの振幅がほぼ比例して（`out` 2 倍で約 2 倍）増えることを確かめます。
5. 終わったら `tone 0` にし、`out` を保存値に戻します（`tone`・`out` は `w` を打たなければ保存されない）。

## 4. シミュレーションの目安（50.5MHz、I 側だけに音声を直流で入れた準静的な計算）

| 測る所 | 音声なし | 音声 100mV | 200mV | 400mV |
|---|---|---|---|---|
| VR5・VR6 のワイパ | 0.65Vpp | 0.65Vpp | 0.65Vpp | 0.64Vpp |
| L12 一次（D4 のアノード） | 3mVpp | 33mVpp | 64mVpp | 118mVpp |
| Q17 のゲート（L12 二次） | 1mVpp | 16mVpp | 32mVpp | 58mVpp |
| Q17 のドレイン（L13） | 8mVpp | 96mVpp | 185mVpp | 340mVpp |
| Q18 のベース | 2mVpp | 23mVpp | 45mVpp | 82mVpp |
| Q18 のコレクタ（L14） | 56mVpp | 0.68Vpp | 1.29Vpp | 2.25Vpp |
| L14 二次（Q19 のゲート） | 25mVpp | 0.30Vpp | 0.59Vpp | 1.20Vpp |

- 「音声なし」は VR5・VR6 が中点でダイオードがそろっているときのキャリアの漏れです（VR5・VR6 を合わせると約 1/30 に下がる）。
- `out 10`・試験トーン（ALC で −20dBFS に絞られる）のとき、変調器への音声は計算で約 0.1〜0.2V（尖頭）です。
- Q17 のゲート・Q18 のベースは小さく、10:1 プローブでは読みにくいので、Q17 のドレインと Q18 のコレクタで判断します。
