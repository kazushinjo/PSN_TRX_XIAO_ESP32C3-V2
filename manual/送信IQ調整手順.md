# 送信 I/Q の調整手順（不要側波帯の抑圧、基板 Ver 2.0）

基板 Ver 2.0 では、送信音声の 90° 移相を XIAO ESP32C3（U3）の複素 FIR で作ります。計算上の移相はほぼ完全ですが、実機では次のずれが残り、不要側波帯（USB なら LSB 側）が出ます。

| ずれの原因 | ずれの種類 | 直すところ |
|---|---|---|
| PDM 出力の 2 段 RC（R61〜R64・C75〜C78）の I と Q の部品のばらつき | 周波数に比例する位相のずれ（遅延の差）＋わずかな振幅の差 | `iqd`（遅延の補正）・`iqa`（利得の補正） |
| Q15・Q16 の増幅度の差、平衡変調器・キャリアのレベル（VR6・VR7）の差 | 振幅の差（どの音声周波数でも同じ） | `iqa`（大きい場合は VR6・VR7） |
| 平衡変調器（D4〜D7）・合成（L8）・キャリアの経路（VR6・VR7）の RF 側の位相のずれ | どの音声周波数でも同じ位相のずれ | VR6・VR7（5.5）。`iqd` では一部だけ |

調整は、試験トーン（1 本の正弦波）を送信し、不要側波帯が最小になるようシリアルのコマンドで `iqd`・`iqa` を合わせ、RF 側の位相のずれが残るときは VR6・VR7 で合わせます。部品や基板の変更は要りません。

## 1. 目安

計算（`kicad/sim/sideband.py`、[図](../docs/images/sideband_suppression.png)）では、300〜2700Hz の最悪値は次のとおりです。

| 状態 | 不要側波帯の抑圧（最悪値） |
|---|---|
| 部品が定数どおり（理想） | 約 69 dB |
| RC が I/Q で ±3% ずれ、調整なし | 約 32 dB |
| 同上を `iqd`・`iqa` で調整（この手順） | **約 51 dB**（1kHz で約 60dB） |
| さらに RF 側に 1°・0.1dB のずれが残った場合 | 約 39 dB |
| RF 側の位相のずれ（V2 の回路全体の計算 `kicad/sim/full.py`、VR6・VR7 が中点） | 3.1° → 約 31 dB |
| 同上を VR6・VR7 で 90° に合わせ、振幅の差を `iqa` で補正（5.5） | 40 dB 以上（計算では 74 dB） |

実機の仕上がりは RF 側のずれでほぼ決まります。**40 dB 以上なら合格、50 dB 以上なら良好**を目安にしてください。

ずれと抑圧の関係（どちらか一方だけのとき）:

| 位相のずれ | 抑圧 | 振幅のずれ | 抑圧 |
|---|---|---|---|
| 0.25° | 53 dB | 0.05 dB | 51 dB |
| 0.5° | 47 dB | 0.1 dB | 45 dB |
| 1° | 41 dB | 0.2 dB | 39 dB |
| 2° | 35 dB | 0.5 dB | 31 dB |
| 5° | 27 dB | 1 dB | 25 dB |

`iqd` 1µs は、トーン 500Hz で 0.18°、1000Hz で 0.36°、1500Hz で 0.54°、2500Hz で 0.9° の位相に当たります。

## 2. 必要なもの

- 50Ω のダミーロード（1W 以上）
- USB-C ケーブルとパソコン（Arduino IDE のシリアルモニタ、または任意のシリアル端末）
- 不要側波帯を見る受信設備（どちらか）
  - **SDR（RTL-SDR など）＋パソコンのスペクトラム表示**（SDR#・SDR++・GQRX など）。数値（dB）で読めるのでおすすめ
  - **別の 50MHz の受信機**（CW モードの狭いフィルタがあるもの）。耳と S メーターで最小点を探す
- PTT スイッチ（マイクコネクタの 3 番を GND に落とせるもの。マイクのままでもよい）
- （あれば）オシロスコープ（6.2 で VR6・VR7 のレベルをそろえるとき）

## 3. 準備

1. Idq（VR2）、出力 LPF（TC2 → TC1）の調整を先に済ませておきます（組み立て説明書 7 章）。
2. 後面の **ANT** にダミーロードをつなぎます。**アンテナにはつながないでください**（調整中は不要側波帯を含む電波が出ます）。
3. ケースのふたを開け、XIAO の USB-C をパソコンにつなぎ、シリアルモニタを **115200bps・改行（LF）あり** で開きます。
4. 最新のスケッチ（2026-10-28 以降）が入っていることを確かめます。`dsp` と入れると設定が表示されます。

   ```
   dsp
   dsp: マイク +0.0 dB / 出力 10 % / I/Q 遅延 +0.00 us / I/Q 利得 +0.00 dB / USB / トーン 0 Hz
   dsp: ALC -20.0 dBFS から
   ```

   今の `iqd`・`iqa` の値を書き留めておきます（失敗したときに戻すため）。

5. 調整中だけ出力レベルを下げます（変調器ドライブのひずみを減らし、測定を見やすくするため）。

   ```
   out 5
   alc -20
   ```

   > `out 5` のままで保存（`w`）しないでください。7 章で元に戻してから保存します。

## 4. 受信設備の準備

### 4.1 SDR で見る場合（おすすめ）

1. SDR のアンテナ端子に短い線（数十 cm）をつなぎ、ダミーロードの近くに置きます。**SDR を直接ダミーロードにつながないでください**（入力が過大になり、SDR 自身のひずみを不要側波帯と見誤ります）。
2. SDR の中心周波数を、送信周波数から **20〜30kHz ずらします**（例: 送信 50.200MHz なら SDR は 50.225MHz）。SDR の中心と送信周波数を同じにすると、SDR 自身の I/Q のずれによる像がちょうど不要側波帯の位置に出てしまいます。
3. スペクトラム表示を次のようにします。
   - 表示幅: 10kHz 前後（送信周波数 ±5kHz が見える）
   - 分解能（FFT の点数）: 10Hz 程度以下になるよう大きく（16k〜64k 点）
   - 平均化: あり（数回〜10 回）
   - 縦軸: dB
4. SDR の利得（RF ゲイン）は、希望波のピークが表示の上端より 30dB 以上下になるよう下げます。利得を下げても不要側波帯と希望波の差（dB）が変わらないことを確かめておくと確実です（差が変わるなら SDR が過大入力）。

### 4.2 受信機で聞く場合

1. 受信機のアンテナ端子に短い線をつなぎ、ダミーロードの近くに置きます。ATT（減衰器）があれば入れ、RF ゲインを下げます。
2. **CW モード・狭いフィルタ（500Hz 以下）** にして、送信周波数 **−1.0kHz**（USB のとき。トーン 1000Hz の場合）に合わせます。ここで聞こえるのが不要側波帯です。
3. 比較のため、送信周波数 **+1.0kHz**（希望波）の S メーターも読んでおきます。S メーター 1 目盛りはおよそ 6dB なので、差が S 7〜8 以上なら約 40dB 以上です（S メーターは目安です）。
4. 調整は「−1.0kHz の音が最も小さくなる点」を耳で探します。

## 5. 調整

本機の送信周波数（LCD の表示）を F とします。USB で試験トーン f を送ると、**希望波は F＋f、不要側波帯は F−f、搬送波の漏れは F** に出ます。

![不要側波帯の抑圧（計算）](../docs/images/sideband_suppression.png)

### 5.1 搬送波の漏れ（VR3・VR4）

不要側波帯の近くに大きな搬送波があると読み取りにくいので、先に搬送波を下げます。

1. `tone 0`（トーンなし）にして PTT を押します。
2. F に出る搬送波が最小になるよう VR3（I 側の変調器）と VR4（Q 側）を交互に少しずつ回します。
3. 希望波（次の手順でトーンを出したとき）より 40dB 以上低ければ十分です。

### 5.2 側波帯の向きの確認

1. `tone 1000` と入れ、PTT を押します。LCD に「ALC 8dB」程度が出ます（トーンは ALC の効き始め −20dBFS に抑えられます）。
2. F＋1.0kHz に大きなピーク（希望波）、F−1.0kHz に小さなピーク（不要側波帯）が出ることを確かめます。
3. **F−1.0kHz の方が大きい**場合は側波帯の向きが逆です。`sb lsb` と入れて入れ替えます（USB で送信したいのに逆になる配線・部品のときは、以後も `sb lsb` のまま使います）。

   > 2 倍・3 倍の高調波（F＋2kHz・F＋3kHz など）がわずかに見えることがあります。これはトーンのひずみで、調整の対象ではありません。見るのは **F−1.0kHz だけ** です。

### 5.3 1 回目: トーン 1500Hz で `iqa` と `iqd` を合わせる

通過域（300〜2700Hz）の中心付近で合わせます。

1. `tone 1500` にして PTT を押し、F−1.5kHz の不要側波帯のレベルを読みます。
2. **`iqa`（振幅）を合わせる**: `iqa 0.2` → `iqa -0.2` と入れて、不要側波帯が下がる向きを見ます。下がる向きに 0.1dB ずつ動かし、最小の点を探します。最小の点の前後を 0.02dB ずつ動かして追い込みます。
3. **`iqd`（位相）を合わせる**: `iqd 2` → `iqd -2` と入れて、下がる向きを見ます。下がる向きに 0.5µs ずつ動かして最小の点を探し、前後を 0.1µs ずつ動かして追い込みます。
4. 2〜3 を 2〜3 回くり返します（振幅と位相はほぼ別々に効くので、すぐに収まります）。

   コマンドを入れるたびに設定が表示されます。送信したまま入れてかまいません（係数はすぐに切り替わります）。1 回の送信は 30 秒程度にし、ときどき PTT を離して終段を休ませてください。

### 5.4 2 回目: 低い音と高い音のつり合いをとる

RF 側に位相のずれ（どの音声周波数でも同じ）が残っていると、1500Hz では深く下がっても、低い音か高い音のどちらかで抑圧が浅くなります。`iqd` は周波数に比例する位相しか直せないので、両端のつり合いをとります。

1. `tone 500` で F−0.5kHz、`tone 2500` で F−2.5kHz の不要側波帯を読み、それぞれの**抑圧（希望波との差）**を記録します。
2. 2 つの抑圧の差が 6dB 以上あれば、`iqd` を 0.2µs ずつ動かし、**両方の抑圧がほぼ同じになる点**にします（片方を深くするともう片方が浅くなります）。
3. `tone 1000` で振幅だけもう一度確かめ、必要なら `iqa` を 0.02dB ずつ直します。
4. 最後に 500・1000・1500・2500Hz の抑圧を記録します（8 章の表）。いちばん浅い値がこの機械の最悪値です。

### 5.5 RF 側の位相を VR6・VR7 で合わせる（5.4 でつり合いがとれないとき）

VR6・VR7 はキャリアのレベルだけでなく、変調器に入るキャリアの位相も変えます。回路全体の計算（`kicad/sim/full.py`）では、VR6・VR7 が中点のとき I と Q の出力の位相差が 93.1° で、RF 側だけで抑圧が約 31dB に制限されました。VR7 を回すと位相差は 96.9°（0.1 側）〜91.1°（0.9 側）、VR6 を 0.9 側にすると 90.9° まで動き、VR6 0.9・VR7 0.6 付近で 90.0° になりました（振幅は 0.7dB ずれるので `iqa` で補正）。7T50 の実物の値で位置は変わるので、次の手順で合わせます。

1. `tone 1500` で 5.3 の最小の状態にしておきます。
2. VR7 をほんの少し（1/20 回転程度）回し、`iqa`・`iqd` をもう一度最小に合わせます。前より深く下がれば同じ向きに、浅くなれば逆向きに回します。
3. VR7 だけで足りないときは VR6 も同じように少しずつ回します。
4. 2〜3 を、F−1.5kHz が最も深くなり、5.4 の 500Hz と 2500Hz の抑圧の差が小さくなるまでくり返します。
5. VR6・VR7 を回すとキャリアのレベルと搬送波の漏れも少し変わるので、最後に 5.1（VR3・VR4）を確かめます。

## 6. うまくいかないとき

### 6.1 症状と対策

| 症状 | 考えられる原因・対策 |
|---|---|
| どの値でも不要側波帯が 20dB 程度までしか下がらない | 搬送波の漏れやトーンのひずみを読んでいる（周波数を確認）。SDR の中心周波数が送信周波数と同じ（4.1 の 2）。SDR が過大入力（4.1 の 4） |
| `iqa` が ±1dB を超えないと最小にならない | VR6・VR7（キャリアのレベル）が大きく違う（6.2）。Q15・Q16 の hFE が大きく違う（同じロットに替える）。R61〜R64・C75〜C78 の値の取り違え |
| `iqd` が ±10µs を超えないと最小にならない | C75〜C78（3300pF）または R61〜R64（3.3kΩ）の値の取り違え・はんだ不良。2 段 RC の I と Q で部品を入れ替えていないか |
| 1500Hz では 50dB 以上なのに、500Hz か 2500Hz で 35dB 以下 | RF 側の位相のずれが 1〜2° 以上ある。5.4 でつり合いをとる。VR3・VR4（変調器のバランス）を合わせ直すと変わることがある |
| 送信の最初の 0.45 秒だけ音が出ない | 正常（送信開始時の音を出さないため、スケッチが 0.45 秒無音にしている） |
| 調整した値が電源を入れ直すと戻る | `w` で保存していない（7 章） |

### 6.2 VR6・VR7（キャリアのレベル）をそろえる

`iqa` で振幅の差が直せないときだけ行います。

1. `tone 0` にして PTT を押し、送信状態にします（V2 では受信中の CLK0 は局発の 38〜39MHz、CLK1 は止まっているので、送信中に見ます）。
2. オシロスコープで VR3 と VR4 のワイパー（C39・C40 の変調器側）の 50MHz の振幅を見て、VR6・VR7 で同じ大きさ（0.3〜0.5V ピーク程度）にそろえます。そろえたあとで 5.5 の位相合わせをすると、振幅は少しずれますが `iqa` で補正できます。
3. 5.1 からやり直します。

オシロスコープがない場合は、VR6 と VR7 を同じ回転位置にしてから 5.3 の `iqa` で合わせます。

## 7. 仕上げ（保存）

1. 出力レベルと ALC を通常の値に戻します。

   ```
   tone 0
   out 10
   alc -20
   ```

2. `dsp` で表示を確かめ、`w` で保存します（`iqd`・`iqa`・`sb`・`out`・`alc`・`mic` がまとめて保存されます。トーンは保存されません）。
3. マイクで話して、ALC メーターが 9 付近から少し赤い目盛りに入る程度になるよう `mic` を合わせます（取扱説明書 4.8）。`mic` を変えたら `w` で保存します。
4. USB ケーブルを外し、ふたを閉めます。

## 9. 参考: コマンド一覧（調整に使うもの）

| コマンド | 範囲 | 内容 |
|---|---|---|
| `dsp` | — | 設定と動作状態の表示 |
| `tone <Hz>` | 0〜3000 | 試験トーン（送信中にマイクの代わりに出す）。0 で止める。保存されない |
| `iqd <µs>` | −20〜+20 | I/Q の遅延の補正。＋で I 側を遅らせる |
| `iqa <dB>` | −2〜+2 | I/Q の利得の補正。＋で I 側を上げる |

| `out <%>` | 5〜100 | 出力レベル（変調の深さ）。標準 10 |

| `w` | — | 設定を保存 |
