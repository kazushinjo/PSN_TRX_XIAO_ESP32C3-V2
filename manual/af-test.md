# マイクアンプ → ADC の AF 信号確認（PC の USB オーディオを信号源にする）

PC の USB オーディオドングルから試験用の正弦波を出し、アッテネータで数 mV に下げてマイクコネクタ（J7）に入れます。
マイクアンプ（U5A）の出力と XIAO の ADC 入力（D2/A2）で、波形・レベル・位相を確認します。

## 1. アッテネータ（−40dB）

```
 ドングル                                        マイクコネクタ J7
 ヘッドホン出力
 (L 側)  ──[ C1 1µF ]──[ R1 10kΩ ]──┬──(−)[ C2 10µF ](+)──── 2番 MIC
                                    │
                                 R2 100Ω
                                    │
 (GND)   ───────────────────────────┴───────────────────────── 4番 GND
```

| 部品 | 値 | 役割 |
|---|---|---|
| R1 | 10kΩ | 分圧の上側。ドングルから見た負荷も約 10kΩ になり、出力に負担をかけない |
| R2 | 100Ω | 分圧の下側。出力側のインピーダンスが約 100Ω と低いので、本体側のバイアス（4.7kΩ）の影響をほとんど受けない |
| C1 | 1µF（フィルム、なければ電解） | ドングル出力の直流を止める保険。なくても動くことが多い |
| C2 | 10µF 電解（16V 以上） | **必須**。MIC 端子には本体から +5V → 1kΩ → 4.7kΩ のバイアスがかかっていて、開放時は約 5V になる。これを R2 に流さず、ドングル側にも入れないため。**＋側を J7 の 2 番（MIC）に向ける** |

- 減衰量は 100 ÷ (10k + 100) で約 1/100（−40dB）。ドングルの出力が 0.3V なら約 3mV、1V なら約 10mV になる
- 低い周波数の落ち始めは、C2 と 4.7kΩ で約 3Hz、C1 と 10kΩ で約 16Hz。音声帯域には影響しない
- もっと下げたいときは R2 を 10Ω にする（−60dB、1V で約 1mV）。抵抗を差し替えるかスイッチで切り替えると、2 段階で使える
- 線はシールド線にし、アッテネータは J7 のすぐそばに置く

## 2. レベルの合わせ方

1. ドングルの L 側だけを使う（R 側は使わない）。GND は 3.5mm プラグのスリーブ
2. PC でトーンを出す。WaveGene や Audacity の「トーン生成」などで 1kHz の正弦波を出す
3. PC の「音声の強調」やイコライザなどの効果はすべて切る
4. ドングルの出力（C1 の前）をテスターの AC レンジかオシロで測り、PC の音量で合わせる。アッテネータの後はその 1/100 になる
   - 安いテスターは 1kHz では正確でないことがある。測るときだけ 100〜400Hz に下げると確実
5. 目安は 2〜10mV。一般的なエレクトレットマイクは、1Pa（話し声を近くで出したくらい）で数 mV〜10mV 程度を出すので、実際のマイクに近い状態になる

## 3. 確認方法

確認はすべて送信状態で行う。出力にダミーロードをつなぎ、PTT（J7 の 3 番）を GND に落とす。ファームウェアがマイクを読むのは送信中だけ。

### 3.1 オシロで比べる（波形・位相）

| チャンネル | 当てるところ |
|---|---|
| CH1 | U5A の出力（1 番ピン） |
| CH2 | XIAO の D2/A2 ピン（GPIO4、AF_ADC） |

- どちらも AC 結合にし、トリガは CH1 にする
- 波形の形が同じで、ずれ（位相差）が小さいことを見る。間の C65・R52 と R73/R74 のバイアスによる、わずかな進みや遅れは正常
- DC 結合に切り替え、A2 の中心が約 1.65V にあり、振幅が 0〜2.5V（ADC の範囲）に収まっていることを見る
- 周波数を 300Hz・1kHz・2.7kHz と変え、振幅と位相が大きく変わらないことを見る（音声帯域の特性）

### 3.2 オシロがない場合（シリアルで確認）

送信中に信号を入れたまま、シリアルから `dsp` を打つ。

- 「入力ピーク」が信号を止めたときより十分大きい → マイクアンプから ADC まで信号が届いている
- 「クリップ」「ADC あふれ」が増えていない → 入れすぎていない

これで分かるのはレベルだけで、位相は分からない。`tone` コマンドはマイクの代わりに内部で正弦波を作るので、この確認には使えない。

## 4. 補足

- **SSB では、マイクアンプ → ADC の位相はほとんど問題にならない。** I と Q の 90° の位相差は、ADC で読み込んだ後にファームウェアで作っている。マイクアンプから ADC までの位相のずれや極性の反転は I・Q の両方に同じように加わるので、逆側の側帯波の抑圧には影響しない。この区間で確認すべきなのは、信号の大きさ・歪み・帯域
- 側帯波の抑圧（I/Q の位相）は、[`送信IQ調整手順.md`](送信IQ調整手順.md) のとおり `tone 1000` と `iqd`・`iqa` で合わせる
- **グラウンドループ**：PC と本体（XIAO）を USB でつないだまま、ドングルも同じ PC に挿すと、GND がループになりハムが乗ることがある。気になるときは、片方を外すか、ノート PC をバッテリー駆動にする
