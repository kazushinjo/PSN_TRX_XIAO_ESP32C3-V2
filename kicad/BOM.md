# PSN_TRX V2 部品表（BOM）

50MHz 帯 PSN 方式 SSB トランシーバ V2（受信部は IF 12MHz の SSB シングルスーパー）。回路図 (`PSN_TRX.kicad_sch`) から `kicad-cli sch export bom` で自動生成した [`bom.csv`](bom.csv) を整形したもの。

> **購入先（2026-10-15）**: 各表の「購入先」「購入先の型番（販売コード）」列は [`make_bom_purchase.py`](make_bom_purchase.py) で入れたもの。秋月電子の型番・販売コードは 2026-10-15 に秋月の通販サイトで確認済み。入数・価格・代替品のメモ付きの一覧は [`bom_purchase.csv`](bom_purchase.csv)（Excel でそのまま開ける）。「要確認」は秋月で扱いがないか、型番・在庫・販売コードを確かめていない部品（3SK59・2SK439・1N60・FCZ コイル・RD06HVF1・L5・L13/L14・マイクコネクタ・電源スイッチ。V2 で増えた NJM2594V・J310・12MHz 水晶・T30-6 と、一部の抵抗・コンデンサ）
> - 代替品: D1 は 1N4001 の代わりに秋月の **1N4007**。C51・C56・C53・C57（47pF）は 2.54mm ピッチ品がないので 5mm ピッチ品の足を寄せて使う
> - IC1（R-78E5.0-1.0）・K1（G5V-2-DC12）・VR2（3266W-1-501LF）は秋月に扱いがなく DigiKey／Mouser。秋月の R-78E5.0-0.5 は 0.5A 品、3296W は外形が大きく基板に合わない

> **V1（PSN_TRX_XIAO_ESP32C3）での変更の履歴**（部品番号・役割は当時のもの）
> - **基板 Ver 2.1: IC2 の電源パスコン C79 を追加（2026-10-28）**: +5V ネットのコンデンサが C55（10µF）だけで、IC2（NJM2904）の電源ピンの近くにパスコンがなかったため、C79（0.1µF、円板セラミック 2.5mm ピッチ）を IC2 の 8 番ピンの近く（右下）に追加。部品 201 → 202 点
> - **基板 Ver 2.0: 送信の I/Q をデジタルで生成（2026-10-21）**: AF の 90° 移相を、アナログのオールパス（IC2A・IC2B・VR8）から **U3（XIAO ESP32C3）のファームウェア**に移した。マイク音声を A2 の ADC で読み、複素 FIR（127 タップ、300〜2700Hz）で I・Q を作り、PDM で **D10（I）・D8（Q）** に出して 2 段 RC（R61〜R64・C75〜C78）で平滑して変調器へ入れる。計算上の逆側帯波の抑圧は 70dB、RC が I/Q で ±3% ずれても iqd・iqa の補正で約 50dB。**削除: T1（ST-71）・VR8・R53〜R57・C69・C70**。**追加: R58（620Ω）・R59（22k）・R61〜R64（3.3k）・C73（1µ）・C75〜C78（3300p）**。**変更: IC2A をマイクアンプ（R36 20k・R40 1k・C54 10µ 電解）**、IC2B は未使用。送信検出を D8→**D0** に。A2 は受信中は受信音（S メーター・AGC）、送信中はマイク。D10 は受信中は AGC の PWM、送信中は PDM の I
> - **PA 出力 LPF を 7 素子＋2 倍波トラップに（2026-10-17、基板シルク Ver 1.8）**: アマチュア局の新スプリアス規定（50MHz 帯: 1W 以下は 50µW 以下、1W を超え 50W 以下は −60dBc）を満たすため、5 素子（2 倍波の減衰 −27〜−31dB）を 7 素子チェビシェフ（カットオフ約 56MHz）にし、中央に 101MHz の直列共振トラップを付けた。C6-L3-（C4＋TC1）-L16-（C71＋トラップ）-L1-C1 の順。**C6 を 33p→39p、C1 を 56p→68p、L3 を 9T に、L16（10T）・C71（100p）を追加**、トラップは **L17（T-30-6 8T ≈ 0.23µH）＋C72（5p）∥TC2（10p トリマ）**。ngspice の計算で、L1/L3/L16 ±7%・Coss 18〜25pF の範囲で TC1 8〜16pF、TC2 5〜6.5pF に合わせると、2 倍波 −70〜−76dB、3 倍波 −75〜−80dB、挿入損失 0.41〜0.53dB、反射減衰量 22dB 以上。**TC2 は 2 倍波が最小になるように必ず合わせる**（合わせないと −30dB 程度に戻ることがある）
> - **アナログ部の動作点・フィルタ特性の検証（2026-10-16、基板シルク Ver 1.6）**: KiCad 同梱の ngspice で、各段の直流動作点（電源 11〜13.8V、hFE 下限〜上限）と AF・RF フィルタの特性を計算して修正した。(1) **マイク系**: C66・C62 を 1µ→**10µ**（T1 との直列共振で 300Hz 付近が +7〜17dB 持ち上がっていた）、**C65 を 0.01µ・C63 を 0.068µ** に（1µ では 15mH と Q18 の 1kΩ に合わず、1kHz を基準に 2.7kHz で −12dB、途中に山と谷があった）。変調器入力で 300〜2700Hz が +1〜−3dB に。**C62 は向きを反転**（＋を L15 側に）。(2) **PA 出力 LPF**: **C6 を 56p→33p**（Q3 の Coss 約 18pF が並列に入り、TC1 をどこに合わせても反射減衰量が 10〜13dB しか取れなかった）、**C4 を 100p→82p**（最適な C4＋TC1 が 90〜106pF のため）。(3) **R6 を 470→330Ω**（RD06HVF1 の Vth は最大 4.9V。ゲート電圧の上限を約 6.2V→7.2V に）。VR8 の合わせ値の記載を 5.6kΩ→5.1kΩ（約 310Hz）に訂正
> - **部品番号の振り直し（2026-10-15）**: 部品番号を回路図の位置順（X 座標の小さい順、同じ X は Y の順）に振り直した。欠番（旧 C26・D4・R20・LED1）はなくなり、XIAO ESP32C3 のソケットは U3 になった。新旧の対応は [`refdes_map_2026-10-15.csv`](refdes_map_2026-10-15.csv)。接続・部品・基板の配置と配線は変わらない（ネットリストの接続は振り直し前と同じ、DRC・ERC も同じ結果）。この表の番号はすべて新しい番号
> - **PTT 回路の修正（2026-10-15、基板シルク Ver 1.4）**: Q1 のベースが PTT につながっておらず（ベースは R1 経由で自分のコレクタへ、エミッタが PTT）、PTT スイッチにリレーのコイル電流がそのまま流れていた。**Q1 を PNP の 2SA1015 に替えてハイサイドスイッチに**（エミッタ = PWR_IN、コレクタ = K1.16、K1.1 = GND）、**R1 を 4.7kΩ のベース抵抗（ベース↔PTT）**に、**R2（10kΩ、ベース↔エミッタ）を追加**、D1 の向きをコイルに合わせて反転。PTT を GND に落とすとベース電流約 2.4mA で Q1 がオンし K1 が入る。PTT の電流は約 2.4mA、開放時の PTT 端子は R1＋R2 経由で 12V
> - **S メーター・AGC・送信検出を追加（2026-10-14〜15、基板 Ver 1.3）**: リード部品 12 点（縦置き抵抗 8・円板セラミック 2・2SC1815 2）を追加。基板は元の 134×108 mm のまま。RF 部（ANT/T-R/PWR・TX RF・RX RF・VFO）は元の配置・配線のまま、AF・DIGITAL 部だけを配置し直して入れた（ケースは変更なし）。エンコーダ SW を XIAO の D2 → D9 に変更
> - 回路図論理検証（第2版）の修正を反映: **R41・R43（100kΩ）追加**（IC2A の Vcc/2 バイアス）、**C4（82pF NP0）追加**（PA 出力 LPF）、**L1・L3 を T-50-10 6T に変更**（旧 18T）、**C7 を 0.001µF に変更**（旧 100pF）
> - Q2 は 3SK59（TO-72、挿入部品）。旧 BOM の BF998（SOT-143）から変更済み
> - **論理チェック（2026-10-11）**: 電解 C43・C66・C48・C68・C44 の向きを直流電圧に合わせて修正、XIAO 5V ピンに逆流防止ショットキー D8（1N5819）を追加、R11 を 100Ω に変更（12V 動作での Q8 損失対策）
> - **論理チェック（2026-10-12）**: TO-92 トランジスタ・FET と Q3 のピン配置を実部品に合わせて修正（シルクの平面側に合わせて挿せば正しく付く。下記トランジスタ表の備考参照）、R52 を 2.2kΩ に変更（12V 動作でのマイク電圧対策）、K1 を **12V コイル品（G5V-2 DC12）** と明記
> - **論理チェック第2回（2026-10-12）**: 送信 12V に **C13（100µF）** を追加、マイク電源を **R51（470Ω）＋C67（47µF）** で送信 12V から分離し **R52 を 4.7kΩ** に、PA 出力 LPF を **5 素子**に（**C6・C1（56pF NP0）** を追加、**L1・L3 を T-50-10 8T** に）、エンコーダ A 相を XIAO の **D0 → D3** に変更（起動設定ピン GPIO2 を避ける）。基板シルク「Ver 1.2」
> - **回路図の見直し（2026-10-11）**: L8 のセンタータップを GND に、Q8 コレクタを L6 の 1 番に修正。C54=0.1µF、R32・R29=22Ω、R3=100kΩ に修正
> - **Q2 は選択式**: 3SK59（Q2）または J310 カスコード（Q4 上段 + Q5 下段、SOT-23、基板裏面）の**どちらか一方のみ実装**する。J310 使用時は R5 を実機で調整（下記 R5 の備考参照）
> - IC1（5V）を **DC-DC コンバータ R-78E5.0-1.0**（78xx 互換、1A）に変更し、PWR_IN から **L12（10µH）・C52（10µF）** の入力フィルタ経由で常時給電（送信中も 5V/3.3V 系が動作、LCD を含めても発熱しない）
> - J11 は廃止済み。PTT は J10（MIC-IN）の 3 番ピンで、Q1（PNP）が K1 のコイルを 12V 側でオンオフする
> - **基板 Ver 1.5（2026-10-16）**: 空いていた **IC2B を I 側の AF オールパス**に使用（**R53〜R57・C69・C70** を追加、C49 の向きを反転。逆側帯波の抑圧が 300〜2700Hz の最悪値で約 6dB → 約 18dB）、**R27 を 1W** に（静止電流で最大約 0.5W 消費するため）、**C4 を 100pF** に（TC1 が回しきりにならないように）、放熱器を **17PB046（11.9℃/W）** に変更
